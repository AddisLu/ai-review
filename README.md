# AI 總複習學習站

在樹莓派上執行的家庭學習網站：手機、平板、電腦連上同一個 Wi-Fi 就能使用。
專為國小五、六年級總複習設計，AI 使用 Claude（`claude-opus-5-5`）。
預設使用樹莓派上 Claude Code 登入的 **claude.ai 帳號（訂閱方案）**，不需要 API 金鑰；用量算在訂閱方案的額度內。也可以改用 API 金鑰。

- 網址：`http://raspberrypi.local:8000`（或 `http://<樹莓派 IP>:8000`；外出時可用 Tailscale IP）
- iPad / iPhone：Safari 開啟後「分享 → 加入主畫面」，就像 App 一樣使用

## 帳號（每個孩子各自登入）

- 第一次打開網站會請你建立**家長帳號**（密碼）和**第一個孩子**（年級＋4~6 位數字密碼）。
- 之後在「我的 → 家長專區 → 帳號」新增其他孩子（例如三年級的妹妹、同年紀的表妹）或其他家長。
- **題庫全家共用**（題目、答案、詳解、圖解），**錯題是個人的**：每個人的錯題、螢光筆／記號、收藏、備註、複習排程、錯的次數與寫錯的答案都分開記錄。
- 孩子預設只看到自己年級程度的題目（可切換全部年級）；只有加入題目的人或家長能修改題目內容。家長可以把題目「加入錯題本給…」任一個孩子。
- 考卷照片與練習紀錄、XP／徽章是個人的。
- 家長帳號可以點左下角頭像切換「要看誰的資料」，也能用自己的帳號測試所有功能。
- AI 會依登入孩子的年級調整說明深淺；學習地圖有三到六年級單元，心算快打依年級出題。

## 第一次使用

1. 打開網站 → **我的 → 家長專區**（預設家長密碼 `0000`）→ **設定**
2. AI 設定應顯示「Claude Code 已登入」，按「測試連線」。
   若顯示未登入：在樹莓派終端機輸入 `claude`，再輸入 `/login`，用你的 claude.ai 帳號登入。
   （若想改用 API 金鑰，在同一區塊選「用 API 金鑰」並填入。）
3. 修改家長密碼；若要開放到外網，請設定「網站密碼」
4. 在「印表機」區塊確認或加入印表機

## 三大功能

### A. 拍照 → 可編輯試卷 + 詳解
- 自動找紙張邊緣、透視校正、去陰影
- 移除彩色筆跡（藍筆答案、紅筆批改、螢光筆），以及 AI 定位的鉛筆／原子筆筆跡 → 還原空白考卷
- 每題轉成可編輯文字（數學式、注音、填空格），附圖自動裁切
- 自動判斷：老師打勾／打叉、螢光筆畫過的題目、學生加星號／圈起來的題目、學生原本的答案
- 每題附：答案、步驟、詳解、三層提示、重點觀念、題型解析、常見錯誤、線段圖
- 依科目 → 單元 → 題型彙整；錯題本使用間隔重複（1→2→4→7→15 天）安排複習
- 漏掉的題目可「框選新增」；沒擦乾淨的地方可「手動修圖」（擦除／還原筆刷）
- 組卷：A4 直印／橫印、單欄／雙欄、字級、作答空間、答案附在最後／另一份解答卷／每題下方、直書
- 匯出 PDF、Word；直接送到印表機

### B. 單元重點與題型解析
- 五、六年級數學、國語、自然、社會、英語單元大綱（可自訂單元）
- 每個單元：重點觀念、公式卡（含代入例子）、常考題型（認法＋步驟＋例題）、易錯點、口訣、生活應用
- 用國小五、六年級聽得懂的語言撰寫；可讓 AI 依單元出題、闖關拿星星

### C. 數學手寫 AI 分析
- 平板電子計算紙：感壓筆、橡皮擦、復原、只用觸控筆（防手掌誤觸）、可加長紙張
- 「給我提示」：AI 看目前寫到哪裡，給下一步提示（三層，不直接給答案）
- 「請 AI 批改」：逐行辨識算式、標出第一個錯的步驟、錯誤類型（觀念／計算／題意／抄寫／單位／粗心）、重新講觀念、給訂正提示
- 每題還有 AI 小老師聊天（蘇格拉底式引導）

## 手寫計算紙（像 GoodNotes / Samsung Notes）

- 題目一直看得到：橫向平板／電腦在左邊一欄（圖比較大，點圖放大），直向在上方。
- 筆：再點一次「筆」打開設定——鋼筆（跟著力道變粗細）／原子筆（粗細一樣）、三種粗細＋滑桿、9 種顏色。
- 螢光筆：三種粗細、四種顏色，畫在字的下面不會蓋住字。
- 橡皮擦：小／中／大；「整筆擦掉」或「只擦碰到的部分」；S Pen 按住側鍵寫就是橡皮擦；側邊圓鈕一下切換筆 ⇄ 橡皮擦（網頁收不到 Apple Pencil 點兩下）。
- 套索：圈起來可以拖動、刪除、複製、換顏色。
- 筆畫停住半秒變直線（分數線、數線、幾何圖）。
- 紙張：方格／橫線／點格／空白；「新頁」訂正用，前一頁還在。
- 紙張沒有邊界（像無邊記）：兩指拖到任何方向、捏合縮放 25%～500%（手指中間的點不會跑掉）；「回到原位」一鍵回到開始的位置，「看全部筆跡」把寫過的全部放進畫面；兩指快速點一下＝上一步；Mac 觸控板捏合。
- 防誤觸：用觸控筆時，手掌和單一手指都不會畫到或移動紙張。
- 用手指寫：沒有觸控筆時一指就是寫字、兩指縮放；工具列的「移動」（手掌圖示）打開後，一指（或筆）拖動紙張、兩指縮放，再點一次回到筆。
- 寫滿一整頁後縮小、換位置、放大也順：螢幕外的筆跡不畫，縮小時用整頁的縮圖移動，手指放開後再畫清楚。
- 筆跡跟著筆壓變化、兩端收尖，正在寫的那一筆在獨立的低延遲圖層上。

## AI 看錯圖時

題目有圖時，AI 解題會先寫下「圖上每個數字量的是哪一段」，看不確定會在題目下方提示。按「AI 看錯圖了？告訴 AI 正確的意思」輸入（例如「11 是 A 到最底下虛線的整段」），AI 會依照說明重新解題，之後的批改、提示都會用這個說明。手寫批改判錯時也可以直接按「我覺得我是對的：AI 是不是看錯圖了？」。拍照時把有圖的題目拍清楚（靠近一點）可以減少看錯。

## 用手機拍考卷（桌機）

桌機的「掃描試卷」一打開就有 QR code：用手機相機掃描後，可以一頁一頁拍，或從相簿一次選多張，照片會即時出現在電腦上；按「完成」就開始整理。手機不需要登入。

## AI 回應速度

- 互動功能（聊天、提示、手寫批改、換方法解說、圖解、家長指南、出練習題）用較快的 Claude Sonnet 5.5；試卷辨識、詳解、重點整理用 Claude Opus 5.5。可在「家長專區 → 設定」改回全部用 Opus。
- 長的工作拆成多個同時進行的小請求再合併：換方法解說（每種講法一個）、錯題卷觀念教學（每個單元一個）、舉一反三（每題一個）、出題（每兩題一批）、單元重點卡（兩半）。
- 先準備好：答錯就先畫圖解；錯第二次就先寫好「換個方法解說」；看提示時先準備下一層提示和例題；孩子按「請爸媽幫忙」時先寫好家長陪伴指南；建立錯題卷時就開始寫觀念教學。同一份工作不會重複送出。
- 手寫批改先在約 7 秒內顯示「對／要訂正」，逐行說明接著補上。
- 「四十八」「五分之三」「二又三分之一」「百分之二十五」等答案直接在本機判斷，不用等 AI。

| 任務 | 怎麼做 |

| 卡住 | 「我卡住了」直接給下一層提示；「請爸媽幫忙」一下就送出，寫過的答案、AI 判斷、問過小老師的話會自動附上 |

## 用平板寫（電腦沒有觸控筆時）

MacBook、Windows 桌機或筆電沒有觸控筆時：在題目的「手寫計算紙」按「用 iPad／手機寫」，用 iPad、S7 FE 或手機的相機掃 QR code，平板就變成計算紙。每一筆都會即時出現在電腦上，平板按「寫好了」就在電腦上 AI 批改，結果也會傳回平板，可以直接用紅筆訂正。平板若已用同一個孩子帳號登入，打開網站會自動跳出「開始寫」，不必掃描。連線 30 分鐘沒動作會自動結束。

## HTTPS（麥克風語音輸入）

`sudo tailscale serve --bg --https=443 http://127.0.0.1:8000` 已設定，網址 https://raspberrypi.<你的tailnet>.ts.net （只有登入同一個 Tailscale 的裝置能開）。瀏覽器只允許 https 網頁使用麥克風；家裡 Wi-Fi 的 http://192.168.1.20:8000 一樣可以用，只是沒有麥克風按鈕。關閉：`sudo tailscale serve --https=443 off`。

## 刷題（快速作答）

- **先對答案，有問題才問 AI**：代號（ㄅㄆㄇ、A～F）、✓ ✗ △ ○、數字直接在樹莓派上比對，不用等 AI；手寫只讓 AI 快速讀出答案再比對。答對就「答對了 → 下一題」（自動跳下一題），不寫 AI 詳解；答錯才出現「AI 幫我看哪裡錯」。
- **直接在題目上作答**：代號題、打勾／畫△題會出現大按鈕，點一下就作答，不用開想法紙。
- **看答案**：卡住時按「看答案」看答案與詳解，這題記為「還沒會」，之後會再出現。
- **題組（承上題）**：2-(2)、3-② 這類小題會在上方顯示題組的說明、代號表或表格。
- **答題紀錄**：每份考卷「練習這一份」會接著做還沒答對的題，「錯過的題」列出練習時錯過的題目和次數。家長帳號選了孩子時，作答預設記在孩子的紀錄（要家長試做時勾「家長試做」）。
- 情境插圖（人物、教室場景）保留原圖並清空作答方格，不再畫成線條圖。

## 錯題卷：先教再練

- 從錯題本或考卷選「組卷列印」，錯題卷預設**依題型分大題（一、選擇題／二、填充題…）並重新編號**。
- 卷首附 AI 整理的**觀念教學重點**（觀念說明、公式、例題、易錯點、圖解），對應到卷上的題號；先讀懂觀念再解題。
- 「線上作答」會先一頁一頁看觀念（動畫圖解），再開始作答；錯題複習時每題上方也有「先複習觀念」。

## 錯越多次，講得越清楚

- 每個孩子每一題錯的次數與寫錯的答案都會累積。
- 錯第 2 次起，題目頁會自動出現「換個方法解說」：AI 依她寫錯的答案推測卡住的觀念，提供 2~3 種**不同的解法**（線段圖、生活情境、倒推法…，不重複之前用過的講法），附圖解、一題「換你試試」和建議先複習的單元。
- 作答答錯時也能立刻按「換個方法講給我聽」。家長報告會列出「最常錯的題目」。

## 圖解（動畫／列印圖）

AI 會挑選合適的圖解模板（分數條、分數圓、數線、面積方格、三角形／平行四邊形／梯形／圓的切割拼補、線段圖、步驟流程、對照表、時間軸、速率路線、直式計算、天平），
網頁上是逐步出現的 SVG 動畫（點一下可重播），列印時是同一張圖的靜態版。

圖解要讓那個年級的孩子「看圖就知道怎麼解」：一張關鍵圖（真實數字、最多 3～4 個標籤、要求的部分標「?」）＋一張步驟圖。
每張圖畫好後，樹莓派會把它實際畫成圖片給 AI 看（數字和題目一致嗎？字有沒有重疊？有沒有直接寫出答案？孩子看得懂嗎？），
不合格就照意見重畫，最多 2 次；還是不清楚就不顯示（沒有圖比看不懂的圖好）。掃描完先出題目和詳解，圖解在背景平行補上。
單元重點卡、錯題卷觀念教學、換方法解說裡的圖也一樣：先顯示文字，圖檢查通過才出現。家長可呼叫 `POST /api/visuals/recheck` 讓 AI 重新檢查全部的圖。

## 錯題頁

- **孩子**：最上面是「我的學習狀況」（學會幾 %、待加強、今天要複習、本週學會、最常錯的原因），一鍵「今天的 N 題」。
  下面依「觀念」整理要加強的錯題（會了幾題、錯幾次、常錯在哪），勾選幾個觀念 → 「馬上練」選：重做錯題／錯題＋AI 類似題／先看觀念教學再練／印成紙本；
  或「先看觀念」直接看重點卡再練。也可以用「錯 2 次以上、螢光筆・記號、最近考卷、已學會回顧」挑題。一題一題看的清單在「一題一題看・管理題目」。
- **家長**：選孩子 → AI 找到的弱點（附原因與建議，可「讓 AI 深入分析」）、為什麼會錯（題意、計算、觀念…比例）、各觀念精熟度表；
  勾選觀念可以印成複習卷或「指派」：觀念＋練習／重做錯題／AI 類似題／紙本卷、題數、期限、金幣獎勵、留言。
  孩子打開「今天」就會看到任務，一按就開始；做完拿到金幣，家長在「指派的任務」看到做了幾題、對幾題。

## 試卷範本

**自己的考卷類型**：試卷範本頁「新增自己的考卷類型」只要打名稱（例如「學校段考」）：排版依名稱自動選、名稱裡的考試字（段考、週考…）成為關鍵字；
掃描後名稱有關鍵字就歸到這類，沒有的話 AI 會比對你的類型名稱判斷（不確定就不歸類）。不滿意在「整理清單」調整（排版、解答樣式、欄數、字級、關鍵字），
不用的類型可以取消勾選，掃描選單就不會出現；改完按「依範本重新產生」更新已拍的考卷。

**掃描給誰**：家長帳號掃描時會先問「這是誰的考卷」（不會放進家長自己的紀錄）；放錯人可以在考卷頁改。手機按「完成」後在背景整理，可以直接拍下一份；
「已拍的考卷」依系列（第幾回）整理，標出還沒拍的回數。

**家長檢查成品**：每份考卷頁最上面有「排成「○○」」卡片——寫著 AI 判斷這是哪一類考卷，一鍵看題目卷、解答卷，直接下載 Word／PDF；
不對就在卡片上換範本。上傳自己的 Word 範本後可以設定「之後的○○都用這個」，以後同類考卷自動套用。

掃描頁可以選「掃描後排成」哪種範本（預設 AI 依試卷名稱判斷）：小考、單元評量、期中考／期末考（學年度學期標題、班級座號姓名得分表、大題得分表、每大題配分）、
模擬考（作答說明：題數、滿分、作答時間）、私中模擬考（補習班：雙欄、連續題號、附詳解與圖解）、錯題複習卷（先教再練）。
「試卷範本」頁依類型分類：每一種範本只用「同類型」掃描過的考卷預覽（還沒有這類考卷就顯示「還沒有」，第一次掃描、AI 整理好後就會出現），題目卷、解答卷（只有答案／答案＋詳解／詳解＋圖解）都能看，也可以下載成 Word：在 Word 改字型、學校名稱、Logo、頁首頁尾…，
保留 `{{題目}}` 等標記再上傳，之後 Word／PDF／列印都照你的檔案排（PDF 由同一個 Word 檔用 LibreOffice 轉出，所以一模一樣）。

## 速度

拍照上傳後會直接進入試卷頁：約 30 秒先顯示辨識好的題目，詳解在背景以小批次平行產生並陸續補上（測試考卷約 80 秒全部完成，原本約 120 秒才看得到結果）。

## 列印

- **送到印表機**：在組卷頁選印表機、份數、單雙面、黑白／彩色。伺服器先產生 PDF 再透過 CUPS 列印。
- **加入印表機**：家長專區 → 設定 → 印表機 → 「搜尋網路印表機」（AirPrint／IPP Everywhere／Mopria，免驅動），或輸入印表機 IP。
- **AirPrint 分享**：打開後，USB 接在樹莓派上的印表機也會以 AirPrint 印表機出現在 iPhone／iPad。
- **用這台裝置列印**：開啟瀏覽器列印對話框（iPad 會出現 AirPrint 印表機）。
- 印表機若因沒開機被 CUPS 停用，可在網頁上按「重新啟用」。

## 安裝到新的樹莓派

```bash
git clone <this folder> ai-review   # 或直接複製資料夾
cd ai-review
./deploy/install.sh
```

腳本會安裝 Chromium（產生 PDF）、CUPS、中文字型（Noto CJK、楷體）、Python 套件，並建立開機自動啟動的 systemd 服務 `ai-review`。

常用指令：

```bash
sudo systemctl status ai-review      # 狀態
sudo systemctl restart ai-review     # 重新啟動
journalctl -u ai-review -f           # 即時紀錄
```

資料（資料庫與照片）在 `data/`。家長專區 → 設定 → 「下載備份」可下載完整 zip。

### NAS 自動同步

家長專區 → 設定 → NAS 自動同步：填入資料夾（例如 `\\192.168.1.10\Public\AI智能複習系統`）、NAS 帳號密碼並啟用。
資料庫本體留在樹莓派（SQLite 不能直接放在網路磁碟上執行），網站會把以下內容同步到 NAS：
資料庫最新備份＋每日備份（保留 30 天）、所有考卷照片與圖片、每位孩子的「錯題本.csv」「練習紀錄.csv」（可用 Excel 開啟）。
掃描完成後立即同步，平常每 10 分鐘檢查一次，只上傳有變動的檔案。NAS 上的「說明.txt」寫有還原步驟。

```bash
.venv/bin/python -m pytest tests     # 後端測試（使用假的 AI，不花費 API 費用）
.venv/bin/uvicorn app.main:app --reload --port 8000
```

- `app/` FastAPI 後端：`imaging.py`（OpenCV 影像處理）、`ai.py` + `prompts.py`（Claude 呼叫與 JSON schema）、
  `pipeline.py`（掃描流程）、`practice.py`（批改、間隔重複、出題選擇）、`gamify.py`（XP／徽章／排行）、
  `exporters.py`（PDF／Word）、`printing.py`（CUPS／AirPrint）
